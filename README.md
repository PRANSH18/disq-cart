# DisQ-Cart

**"Discuss before you Cart." An e-commerce storefront with a social layer, so buyers and sellers can talk before a purchase.**

## The idea

Online shoppers rely on static reviews written by strangers. DisQ-Cart adds conversation to the shopping flow, so a buyer can ask a seller or other buyers a question at the point of decision.

## What it does

- Product catalogue, cart and checkout subtotal
- Buyer and seller interaction on top of the storefront

## Stack

React

## Run locally

Unzip `package.zip`, then:

```bash
npm install
npm start
```
